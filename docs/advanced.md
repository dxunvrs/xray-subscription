## Повышение скорости подключения
Можно пустить трафик в обход сети докера  
1. Меняем ```docker-compose.yml```: комменитриуем секцию ```ports``` и раскомментируем ```network_mode``` и ```user```
2. В конфиге xray ```config.json``` меняем:
```
...
"inbounds": [
    {
      "tag": "dock-api",
      "listen": "172.17.0.1",
      "port": 10085,
      "protocol": "dokodemo-door"
    },
...
```
Теперь xray принимает gRPC-запросы только от докер-сети и закрыт от внешних взаимодействий (так мы компенсируем ```network_mode: host```),
порт для подключения клиентов (в конфиге 443 по умолчанию) доступен минуя докер-сеть
3. Меняем ```.env```
```
XRAY_GRPC_HOST=172.17.0.1
```
4. Готово
